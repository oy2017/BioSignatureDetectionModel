# Sources for v3/data/independent

Retrieved 2026-10-30. Data retrieval only: no classifier or verdict script was run and `v3/results/` was not opened. Downloads were parsed as text with `python -I` from outside this directory. The T18 pickles were not opened.

CSV columns: `wl_um, half_width_um, depth_fraction, err_fraction`. A blank `half_width_um` means no width was given. "LABEL" marks the reduction behind the label; "alt" marks another reduction of the same or similar data.

## Access routes

- **Exoplanet Archive.** `<session>` is `TMP_xxx`, the per-visit token in the HTML of https://exoplanetarchive.ipac.caltech.edu/cgi-bin/atmospheres/nph-firefly?atmospheres. The full path is `/workspace/<session>/atmospheres/tab1/data/<spec_path>`, the form the page's own JS (`tab1.js`) uses for its wget scripts. `spec_path` comes from TAP table `spectra`. Bibcodes are the archive's.
- **T18 zip.** Dropbox ignores HTTP Range, so the whole zip was downloaded to `v3/data/hst/FINAL_ONLINE_DATA_4_REFS.zip`: 7,411,949,460 bytes, sha256 cd129339e61a550fb7edfc35bf3a8855b9d019f294e8c2273513dec0737068a1.
- **Zenodo.** https://zenodo.org/records/20547576 (`data.zip`).

## Caveats on the spectra

- **T18 resolution.** E23 Table cites "T18" without naming a resolution. I chose the 25-bin `high` files because they match the bin grid of every other E23 spectrum. This is an inference. The 18-bin `low` files are saved too.
- **T18 columns.** The `.txt` files have no header. Column order was fixed by matching digits to the archive's copies (HAT-P-32 b, HAT-P-41 b, within 0.5 ppm). GJ 436 b has no such copy and is assumed to share the format. It has four visits; I assume the file is the combined spectrum, since the only per-visit data are in pickles I did not open.
- **Skaf 2020 widths.** The archive leaves BANDWIDTH null. Half-widths are derived from the T18 grid, as logged above.
- **Blank widths.** HAT-P-14 b (both modes), GJ 436 b Knutson 2014, HAT-P-2 b Jacobs 2025 and V1298 Tau c Barat 2024.
- **Asymmetric errors.** Averaged. Only Alam 2020 (HAT-P-32 b) and Alam 2022 (HIP 41378 f) have them, and the two sides differ by at most 3.3 %.
- **V1298 Tau c R300.** `R300` is nominal. Bin width gives lambda/dlambda of about 190-250. Create_Figure5 loads this file with `skiprows=2`, dropping the first bin; the CSV keeps all 275 points.
- **V1298 Tau c HST.** The E23 median depth is 0.1170 %, against Barat 2024 0.1216 % and JWST 0.1265 % over a wider range. No offset was applied.
- **HAT-P-14 b offset.** Liu 2025 fits a 237 ppm SOSS offset and adds it before the final retrieval. The archive note does not say whether the SOSS file includes it. The medians of the two modes differ by only 26 ppm, which suggests it may be applied, but this is not confirmed. Check before combining modes.
- **LTT 9779 b.** The archive has no ApJS E23 file for it. G102 and G141 bins interleave near 1.13 um in the 38-point file. The saved file is Edwards et al. 2023 AJ 166 158, arXiv 2306.13645: Iraclis, proposal 16457, "same methodology" as the population paper. Identity with the ApJS G141 spectrum is not confirmed.
- **WASP-103 b.** The Changeat 2022 archive file is 374 ppm shallower on average than E23 (up to 568 ppm per point). It is not used.

## Changeat 2022 files (`_changeat2022_not_normalized/`)

Kept as originals only. They are not eclipse spectra as the survey suspected. Their depths are at transit scale, and three are copies of transit spectra: HAT-P-32 b and HAT-P-41 b match T18 `high` within 0.5 ppm, and WASP-79 b matches Skaf 2020 within 0.9 ppm. So B1's "looks like a mislabel" does not hold for these three. They add no new data.

## Label checks against the survey

- **V1298 Tau c (Murphy 2026 table).** H2O -1.83 +0.68/-0.77 and -1.59 +0.60/-0.65; CH4, NH3 and CO2 as in the survey. Confirmed: H2O present; CH4, CO2 and NH3 absent. The paper calls Case 2 "fiducial", and Create_Figure3 labels `LCtest2_6spots` as Case 2 (Gaussians), so the survey's inference holds. The retrievals are named `niriss_r300`, so R300 is the retrieved file.
- **HAT-P-14 b (Liu 2025 table).** Values are mass fractions: H2O -2.32 +1.13/-1.40, CO2 -6.58 +2.18/-2.20, CH4 -7.46 +1.96/-1.65; free-T run H2O -2.32 +1.06/-1.41. With mu = 2.33 (assumed, as in the survey) H2O VMR is -4.61 to -2.08, and -4.62 to -2.15 for free-T. Confirmed: H2O None, because the interval straddles -4; CH4 and CO2 absent; NH3 not modelled.
- **LTT 9779 b, new flag.** Edwards et al. 2023 AJ (G102+G141) prefers H2O at 3.1 sigma and calls the abundance "high". It prints no H2O value in the text or tables read (figure only). This disagrees with the B3 absent label from E23 (G141 only). Under the survey's rule the label looks like None; this is the user's decision.
